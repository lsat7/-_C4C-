# 扩展领域测试：微分方程 + 大学物理

说明：本测试用于验证求解器对「微分方程」与「大学物理（力学/电学）」两个扩展领域的支持。

## 微分方程（Differential Equations）

Problem 1. 求解一阶线性微分方程：$y' + 2y = e^{-x}$。

Problem 2. 求解二阶常系数齐次微分方程：$y'' + y = 0$。

Problem 3. 求解一阶微分方程：$y' + y = x$。

## 大学物理（University Physics）

Problem 4. 质量为 $2$ kg 的物体受到 $F = 10$ N 的力，求其加速度 $a$。（牛顿第二定律）

Problem 5. 两个点电荷 $q_1 = 2 \times 10^{-6}$ C 与 $q_2 = 3 \times 10^{-6}$ C 相距 $r = 0.1$ m，求库仑力 $F$。

Problem 6. 物体从高度 $h = 20$ m 处自由落体，求落地时间 $t$（取 $g = 9.8$ m/s²）。
