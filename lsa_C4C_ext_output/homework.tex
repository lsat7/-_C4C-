\problem{1}

求解一阶线性微分方程：$y' + 2y = e^{-x}$。

\solution

微分方程：$2 y{\left(x \right)} + \frac{d}{d x} y{\left(x \right)} = e^{- x}$

通解：$y{\left(x \right)} = \left(C_{1} e^{- x} + 1\right) e^{- x}$

\textbf{Answer:}
\[\boxed{\left(C_{1} e^{- x} + 1\right) e^{- x}}\]

\problem{2}

求解二阶常系数齐次微分方程：$y'' + y = 0$。

\solution

微分方程：$y{\left(x \right)} + \frac{d^{2}}{d x^{2}} y{\left(x \right)} = 0$

\textbf{Answer:}
\[\boxed{C_{1} \sin{\left(x \right)} + C_{2} \cos{\left(x \right)}}\]

\problem{4}

质量为 $2$ kg 的物体受到 $F = 10$ N 的力，求其加速度 $a$。（牛顿第二定律）

\solution

$F = ma \Rightarrow a = F/m$

$F = 10,\; m = 2$

$a = 5$ m/s²

\textbf{Answer:}
\[\boxed{5}\]

\problem{5}

两个点电荷 $q_1 = 2 \times 10^{-6}$ C 与 $q_2 = 3 \times 10^{-6}$ C 相距 $r = 0.1$ m，求库仑力 $F$。

\solution

库仑定律：$F = k \frac{q_1 q_2}{r^2}$，$k = 9\times 10^9$ N·m²/C²

$q_1 = \frac{1}{500000},\; q_2 = \frac{3}{1000000},\; r = 0.1$

$F = 5.4$ N

\textbf{Answer:}
\[\boxed{5.4}\]

\problem{6}

物体从高度 $h = 20$ m 处自由落体，求落地时间 $t$（取 $g = 9.8$ m/s²）。

\solution

自由落体：$h = \frac{1}{2} g t^2 \Rightarrow t = \sqrt{2h/g}$

$h = 20,\; g = \frac{49}{5}$

$t = \frac{10 \sqrt{2}}{7}$ s

\textbf{Answer:}
\[\boxed{\frac{10 \sqrt{2}}{7}}\]
